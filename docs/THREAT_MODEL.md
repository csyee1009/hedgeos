# HedgeOS Security & Threat Model

| Threat Category | Threat Scenario | HedgeOS Mitigation Strategy | Residual Risk |
| :--- | :--- | :--- | :--- |
| **Prompt Injection** | User or malicious input attempts prompt injection to override constraints or extract secrets. | Adversarial prompt validation in `LLMOutputValidator.ts`, strict Zod schema parsing, explicit human confirmation step. | Malformed intent parsed, but blocked at confirmation / policy step. |
| **LLM Hallucination** | LLM fabricates invalid option strikes, excessive budgets, or non-existent assets. | AI output is untrusted. `IntentEngine.ts` enforces fallback default validation and requires explicit human confirmation. | Inferred intent requires user correction before confirmation. |
| **Constraint Weakening** | Inferred financial constraints try to relax user protection targets or budgets. | Intent versioning locks user-confirmed constraints. Financial Constitution enforces strict numeric checks. | User must carefully inspect human confirmation screen. |
| **Stale Intent Version** | Replaying an outdated intent version to modify proposal parameters. | Optimistic concurrency control using `expectedVersion` in `SqliteIntentRepository`. Fail-closed HTTP 409 conflict on version mismatch. | Request rejected. |
| **Proposal Substitution** | Swapping an action proposal payload before execution. | Cryptographic binding via SHA-256 digests (`proposalDigest`, `attestationDigest`, `commitmentDigest`). | Mismatched digest blocks execution commitment. |
| **Digest Tampering** | Mutating target contract, asset, or parameters in proposal payload. | Hash re-computation in `ExecutionCommitmentService` verifies exact match of canonical parameters. | Any character change invalidates the commitment digest. |
| **Simulation Mismatch** | Simulation result differs from proposed action parameters. | `ThetanutsSimulationService` verifies exact match between simulation parameters and proposal digest. | Simulation failure blocks attestation. |
| **Budget Bypass** | Proposal cost exceeds user's `maxPremiumUSDC`. | `FinancialConstitutionEngine` invariant #1 strictly compares normalized base-unit USDC cost to budget limit. | Proposal rejected if cost > maxPremiumUSDC. |
| **Denomination Mismatch** | Comparing 6-decimal USDC cost against 18-decimal token amounts. | `decimalParser.ts` normalizes all currency amounts to common decimal base-unit integer math. | Precision loss or overflow prevented. |
| **Asset Mismatch** | Option underlying differs from user risk asset (e.g. ETH intent vs BTC quote). | `isSameAsset()` check in Financial Constitution and Attestation verifies asset equivalence. | Strategy rejected if underlying mismatch. |
| **Wrong Chain / Protocol** | Proposal targets non-Base chain ID or unsupported protocol. | Hardcoded strict checks require `chainId === 8453` (Base Mainnet) and `protocol === "THETANUTS"`. | Any non-Base or non-Thetanuts target fails closed. |
| **Stale Market Evidence** | Replaying outdated market quotes or execution previews. | Quote evidence timestamps checked; evidence older than 5 minutes marks simulation status `STALE`. | Stale evidence blocks bounded authorization attestation. |
| **Replay Attack** | Reusing a consumed authorization handoff to execute a duplicate trade. | `ExternalHumanAuthorizationHandoffService` tracks consumed handoff states (`CONSUMED`) in SQLite. | Reused handoff fails closed. |
| **Expired Handoff** | Attempting to execute a handoff past its expiration window. | `expiresAtMs` enforced (15-minute sliding window or option expiry). Status evaluates to `EXPIRED`. | Expired handoff rejected. |
| **TOCTOU Market Shift** | Option price or liquidity shifts between preview and external execution. | `HumanReviewRecord` discloses TOCTOU risk; external executor must re-verify bounds before execution. | External execution system must enforce slippage. |
| **RPC Outage** | Base Mainnet RPC node becomes unavailable or returns corrupted data. | `ReadOnlyPortfolioService` catches RPC errors and produces `PARTIAL` / `UNAVAILABLE` without fabricating zero balances. | Portfolio balances marked partial until RPC recovers. |
| **Rate Abuse / Denial** | Attacker floods API endpoints with requests. | `express-rate-limit` middleware applies tier-based limits (30 req/10 min for solve/parse, 300 req/10 min general API). | Excess requests return HTTP 429. |
| **Oversized JSON** | Attacker sends huge payloads to crash server memory. | `express.json({ limit: "64kb" })` rejects payloads > 64KB with HTTP 413. | Request rejected safely. |
| **Secret Leakage** | API keys, Bearer tokens, or private keys printed in logs or errors. | `redactSensitiveText()` filters URLs, tokens, keys, and hex strings. Sanitized error middleware excludes stack traces. | Logs contain redacted placeholders only. |
| **Log Leakage** | Sensitive authorization tokens or cookies logged to console. | Request logger explicitly omits Authorization, Cookie, and request body parameters. | Console logs contain sanitized metadata only. |
| **Database Corruption** | SQLite database file becomes inaccessible or corrupted. | Transactions run with WAL mode (`journal_mode = WAL`); health check `/readyz` pings `SELECT 1`. | Unready DB returns HTTP 503 on `/readyz`. |
| **Unauthorized Signer** | Executable code introduces wallet signers or private key handling. | `tests/custodyBoundary.test.ts` statically scans `src/` for forbidden tokens (`new ethers.Wallet`, `signTransaction`, etc.). | Static scan breaks test build on violation. |
| **Dependency Vulnerability** | Installed npm dependencies contain known vulnerabilities. | CI pipeline and local build run `npm audit --audit-level=high`. | Build fails if high or critical vulnerabilities are introduced. |
| **External Executor Compromise** | The external execution system (outside HedgeOS) is compromised. | Outside HedgeOS trust boundary. External executor must independently verify commitment + authorization package. | HedgeOS status remains `NOT_AUTHORIZED`. |
